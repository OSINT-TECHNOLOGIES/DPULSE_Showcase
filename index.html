About DPULSE
What you're looking at
Each report is real DPULSE output — a local-based GUI desktop tool that turns domain reconnaissance into a single interactive HTML file.
🕸️

Infrastructure Graph

Interactive node graph connecting domain, subdomains, IPs, ports, services and CVEs — filterable and zoomable.

🔍

Core Recon

WHOIS, DNS, SSL, subdomains, email harvesting, social media links — collected and structured automatically.

🛡️

Security Analysis

Open ports via Shodan InternetDB, CVE lookup through NVD API, tech fingerprinting with version detection.

☁️

Exposure Intel

Optional Lunar Domain Exposure integration — infostealer and breach data right inside the same report. Free API, no key needed.

🔗

API Enrichments

Native VirusTotal, SecurityTrails and HudsonRock integrations — bring your own free-tier keys for deeper insights.

💾

Local & Private

Everything stays on your machine. No cloud, no accounts, no telemetry. Scan history stored locally in SQLite.
